# File Pipe

**Pipe your scattered files into order** - define rules once, then automatically move or copy matching files from any folder into the destination you set.

## ✨ Features

- **Rules** - Create rules with multiple source folders, file extensions, and a destination. Folders scanned recursively.
- **Templates** - Start fast with presets (screenshots, images, video, music, downloads, documents etc.).
- **Move or copy** - Per-rule operation mode, plus conflict handling (skip, overwrite, or rename with a suffix).
- **Run your way** - Run rules on demand, or let **daily / weekly schedules** take care of it.
- **History** - Every run is logged with per-file detail; **undo** a run to put files back when possible.
- **Swipe shortcuts** - Configurable swipe gestures on rule cards (edit, duplicate, delete, history etc.).
- **Backup** - Export rules to JSON, import again, optional auto-export and scheduled export (Settings).
- **Look and feel** - Light, dark, black (OLED), system default, optional **Material You** colors.

## 🚀 How to use

1. **Allow storage access** - When the app asks, grant **All files access**. File Pipe needs it to move / copy files around, as per your rules.

2. **Start a new rule** - On **Rules** tab, tap **Add rule**. Pick a template or Start blank, then set the name and icon.

3. **Choose which files** - Add **extensions** (for example `.jpg`, `.pdf`). 

4. **Choose where** - Add one or more **source** folders and pick a **destination**. Turn on **scan subfolders** only if you want matches inside nested directories, not just the folder root.

5. **Choose how they are applied** - Set **move** or **copy** and how **name conflicts** are handled. Optionally add a **daily** or **weekly** schedule so the rule can run in the background.

6. **Save, then run** - Tap **Save**. Before the first run, you can open **Preview** from the toolbar (**eye** icon) to see how many files match. Run with **Run now** on a card, or select several rules and use **Run selected**.

7. **History** lists every run; open one for per-file detail or **Undo** when possible. 

8. **Settings** holds theme, swipe actions, and **export/import** of rules as JSON.

## 📌 Requirements

- **Android 11** or newer (API 30+).
- **Manage all files** permission for broad storage organization.
