# File Pipe

**Pipe your scattered files into order** - define rules once, then automatically move or copy matching files from any folder into the destination you set.

## ✨ Features

- **Rules** - Create rules with multiple source folders, file extensions, and a destination. Folders can be scanned recursively. Optional **advanced filters** (name pattern, size, age, exclude pattern), **hourly / daily / weekly** schedules, and **custom emoji** icons.
- **Templates** - Start fast with built-in presets (screenshots, images, video, music, downloads, documents etc.).
- **Move or copy** - Per-rule operation mode, plus conflict handling (skip, overwrite, or rename with a suffix).
- **Run your way** - Run rules on demand, **simulate** a run to see matches without moving files, or let **hourly / daily / weekly schedules** handle it automatically in the
  background.
- **Notifications** — Scheduled runs post a summary notification with the filenames that moved and an **Undo** action button.
- **History** - Every run is logged with file details (moved, skipped, failed); **undo** a run when possible. **Filter** by outcome (including *no changes*), **sort**, and **group** by date, rule, or status.
- **Swipe shortcuts** - Configurable swipe gestures on rule cards (edit, duplicate, delete, history etc.).
- **App shortcuts** — Long-press the launcher icon to run any of your top 4 enabled rules straight from the home screen.
- **Backup** - Export rules, history and settings to JSON, optional auto-export and scheduled export. Import restores everything. 
- **Look and feel** - Light, dark, black (OLED), system default, **Material You** wallpaper
  colors, **5 preset accents** and **9 palettes**, optional **progressive blur** and **gradient** background.
- **Updates** - **Check for updates** in Settings: GitHub builds use releases from this repo; Play builds use **Google Play** in-app updates. 

## 🚀 How to use

1. **Start a new rule** - On **Rules** tab, tap **Add rule**. Pick a template or Start blank, then set the name and icon.

2. **Choose which files** - Add one or more **extensions** (for example `.jpg`, `.mp3`). Optionally expand **Advanced filters** to set a **filename pattern**, **size / age** limits, or **exclude** patterns.

3. **Choose where** - Add one or more **source** folders and pick a **destination**. Turn on **scan subfolders** if you want matches inside nested directories, not just the folder root.

    1. **Grant folder access** — File Pipe uses the standard system folder picker. No broad
    storage permission is required; access is granted folder by folder and remembered per
    folder.

5. **Choose how they are applied** - Set **move** or **copy** and how **name conflicts** are handled. Optionally add a **hourly**, **daily**, or **weekly** schedule so the rule can run in the background.

6. **Save, then run** - Tap **Save**. Use **Preview** from the toolbar to see matches before a real run. Run with **Run now** on a card, or select several rules and use **Run selected**.

7. **History** lists every run; open one for per-file detail, filter by outcome, or tap **Undo** to reverse the moves when possible.

8. **Customise** — Settings covers theme and palette, gradient, blur, haptic feedback, swipe
   actions, notifications, backup / restore, history retention, and update checks.
